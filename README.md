# Begrünung – GSS Bildergalerie

Statische GitHub-Pages-Galerie mit sechs Vorher-/Zukunfts-Vergleichen.

## Veröffentlichung mit GitHub Pages

1. Alle Dateien und Ordner aus diesem Verzeichnis in ein GitHub-Repository laden. `index.html` muss im Hauptverzeichnis liegen.
2. Im Repository **Settings → Pages** öffnen.
3. Unter **Build and deployment**: **Deploy from a branch** wählen.
4. Branch `main` und Ordner `/ (root)` auswählen und speichern.
5. Nach kurzer Zeit erscheint oben in den Pages-Einstellungen die veröffentlichte Adresse.

## Struktur

- `index.html` – komplette Galerie
- `assets/images/` – optimierte WebP-Bilder

Die Seite verwendet keine externen Bibliotheken und funktioniert direkt auf GitHub Pages.
